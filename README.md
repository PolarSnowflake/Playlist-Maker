# 🎵 Playlist Maker

Android-приложение для поиска треков и создания музыкальных плейлистов с интеграцией iTunes Search API.

## 📱 Основные функции

- Поиск треков по названию или исполнителю (через iTunes API)
- Прослушивание превью треков
- Создание и редактирование пользовательских плейлистов
- Сохранение плейлистов в локальную базу данных
- Поддержка тёмной и светлой темы интерфейса

## 🛠 Технологии

- Язык: Kotlin
- Архитектура: MVVM
- Сетевые запросы: Retrofit 2
- Асинхронность: Kotlin Coroutines
- Базы данных: Room
- Внедрение зависимостей: Koin
- Воспроизведение аудио: MediaPlayer
- Навигация: Jetpack Navigation Component
- UI: XML, View Binding
- CI: GitHub Actions
